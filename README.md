Study Planner
A simple and effective Study Planner application designed to help students organize their study schedules, track subjects, and manage time efficiently.

 Features

 Add, edit, and delete study tasks or subjects

 Set reminders or due dates for assignments

 View your study schedule by day or week

 Mark tasks as completed

 Data saved locally (or to the cloud, if you implemented that)

 Technologies Used

Frontend: HTML, CSS, JavaScript

Backend: Node.js

Database: SQLite / MySQL / Firebase / LocalStorage

Tools: Visual Studio Code, Git, GitHub

 How to Use

Add your subjects or tasks for the week.

Set study goals and time slots.

Track your progress and stay organized.

Mark tasks as completed when done!
