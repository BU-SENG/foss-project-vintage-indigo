# Study Smart - Study Planner Application

## About
A simple and effective Study Planner application designed to help students organize their study schedules, track subjects, and manage time efficiently.

## New Features in Frontend-patch-3
- **Dark Mode Support**: Complete dark/light theme toggle with system preference detection
- **Today Progress Widget**: Real-time daily progress tracking with motivational messages
- **Weekly Progress Chart**: 7-day study activity visualization with interactive charts
- **Enhanced Dashboard**: Improved UI with comprehensive progress tracking

## Technologies Used
- Frontend: React.js and Tailwind CSS
- State Management: React Context API
- Icons: Lucide React

## Features
1. Creating a study Session
2. Setting Goals
3. Viewing your Schedule
4. Course Management
5. **Dark Mode** - Toggle between light and dark themes
6. **Progress Tracking** - Daily and weekly study progress visualization
7. **Real-time Statistics** - Study hours, completed sessions, and goal tracking

## Setup Instructions

You need the following software installed:

* [Node.js](https://nodejs.org/en/) (LTS version recommended)
* Git

### Steps

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/BU-SENG/foss-project-vintage-indigo.git
    ```

2.  **Navigate to the Project Directory:**
    ```bash
    cd foss-project-vintage-indigo
    ```

3.  **Switch to Frontend-patch-3 Branch:**
    ```bash
    git checkout Frontend-patch-3
    ```

4.  **Install Dependencies:**
    ```bash
    npm install
    ```

5.  **Start the Development Server:**
    ```bash
    npm start
    ```
    The application should now be accessible at `http://localhost:3000`

## Dark Mode Feature
- Click the moon/sun icon in the header to toggle themes
- Automatically detects your system preference
- Remembers your theme choice across sessions
